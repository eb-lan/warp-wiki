## Как устроена wiki

Статьи находятся в каталоге `content/`. Hwaro превращает Markdown в HTML, а GitHub Actions собирает сайт при каждом изменении ветки `main`. Готовые страницы размещаются на GitHub Pages.

Чтобы читать документацию, устанавливать что-либо не нужно. Навигация слева открывает статьи, оглавление справа помогает перемещаться по длинной странице. На телефоне разделы доступны через кнопку меню в шапке.

## Найти ответ

Нажмите кнопку поиска или сочетание **Ctrl + K** (на macOS — **⌘ + K**). Поиск работает по заголовкам и содержимому статей. Клавиши ↑ и ↓ выбирают результат, Enter открывает его, а Esc закрывает окно.

Светлая и тёмная темы переключаются кнопкой в шапке. Выбранная тема сохраняется в браузере.

## Первая статья через GitHub

1. Откройте [каталог content/guides в репозитории](https://github.com/eb-lan/warp-wiki.github.io/tree/main/content/guides).
2. Выберите **Add file → Create new file**.
3. Назовите файл, например `first-note.md`.
4. Вставьте пример ниже и замените текст своим.
5. Сохраните изменения в `main` или создайте pull request для проверки.

```markdown
+++
title = "Первая заметка"
description = "Краткое описание темы."
weight = 4
+++

## Задача

Опишите, какую проблему решает эта инструкция.

## Решение

1. Выполните первый шаг.
2. Проверьте результат.
```

После сборки новая статья появится в разделе «Руководства» автоматически. Статус сборки доступен на [вкладке Actions](https://github.com/eb-lan/warp-wiki.github.io/actions).

## Работа на компьютере

Установите Hwaro **v0.22.1** из [официального релиза](https://github.com/hahwul/hwaro/releases/tag/v0.22.1). Затем клонируйте репозиторий и запустите локальный сервер:

```bash
git clone https://github.com/eb-lan/warp-wiki.github.io.git
cd warp-wiki.github.io
hwaro serve
```

Откройте адрес, который выведет Hwaro. Сервер обновляет страницы при сохранении файлов. Для отдельной production-сборки используйте `hwaro build` — результат появится в `public/`.

## Что дальше

- Прочитайте статью «Добавление статей» в навигации: она объясняет разделы и порядок страниц.
- Откройте «Форматирование», чтобы увидеть примеры Markdown.
- Загляните в «Публикацию», если сайт пока недоступен на GitHub Pages.
