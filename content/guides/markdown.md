## Заголовки и текст

Главный заголовок страницы берётся из `title`. Внутри статьи начинайте с `##` — такие заголовки также попадают в оглавление.

```markdown
## Основной раздел
### Подраздел

Обычный текст, **важная мысль**, *примечание* и `имя_параметра`.
```

Используйте **жирный текст** для ключевых мыслей, *курсив* для уточнений и `моноширинный шрифт` для параметров, путей и коротких команд.

## Списки

Для последовательных действий используйте нумерацию:

1. Откройте нужный файл.
2. Внесите изменения.
3. Проверьте результат.

Для независимых пунктов подойдут маркеры:

- Короткий заголовок.
- Один вопрос на статью.
- Проверенный пример.

## Примеры кода

Обрамите код тремя обратными кавычками и укажите язык после открывающих кавычек. Например, `bash`, `json`, `python` или `toml`.

```bash
# Собрать сайт в каталог public/
hwaro build
```

У блоков кода есть кнопка копирования, если браузер разрешает доступ к буферу обмена.
