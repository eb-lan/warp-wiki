## Адрес сайта

Этот репозиторий публикуется как сайт проекта:

```text
https://eb-lan.github.io/warp-wiki.github.io/
```

У GitHub Pages адрес вида `имя.github.io` без дополнительного пути доступен репозиторию, название которого совпадает с именем владельца: в этом случае это был бы `eb-lan.github.io`.

## Первоначальная настройка

Владелец репозитория один раз включает публикацию:

1. Откройте [Settings → Pages](https://github.com/eb-lan/warp-wiki.github.io/settings/pages).
2. В блоке **Build and deployment** выберите **Source → GitHub Actions**.
3. На [вкладке Actions](https://github.com/eb-lan/warp-wiki.github.io/actions) откройте workflow **Build and deploy warp-wiki** и запустите **Run workflow**, если публикация ещё не выполнилась.

Не выбирайте `main` как ветку с готовым сайтом: она содержит исходные Markdown-файлы и шаблоны. HTML собирается отдельно.

## Автоматическая сборка

Workflow `.github/workflows/pages.yml`:

1. Получает исходники репозитория.
2. Собирает сайт официальным action Hwaro **v0.22.1**.
3. Проверяет внутренние ссылки, якоря, ресурсы и индекс поиска.
4. Сохраняет готовый сайт в артефакт GitHub Pages.
5. Публикует его, если изменение попало в `main`.

Для pull request выполняется сборка и проверка без публикации. Благодаря этому ошибки можно обнаружить до слияния.

## Проверка перед отправкой

Если Hwaro установлен локально:

```bash
hwaro build
python3 scripts/check_site.py public
```

После проверки сохраните изменения и отправьте их в GitHub. Каталог `public/` коммитить не нужно — его каждый раз создаёт сборка.

## Если что-то не работает

**Сайт возвращает 404.** Проверьте, что в Settings → Pages выбран GitHub Actions, workflow завершился успешно и вы открываете полный адрес с `/warp-wiki.github.io/`.

**Не загружаются стили или ссылки ведут не туда.** Проверьте `base_url` в `config.toml`. Он должен содержать имя репозитория в пути.

**Статья не появилась.** Убедитесь, что файл находится в `content/`, его расширение — `.md`, в начале есть корректный блок параметров и не установлено `draft = true`.

**Сборка остановилась.** Откройте последний запуск Actions и прочитайте сообщение в шаге, отмеченном красным. Исправление в `main` запустит сборку повторно.
