## Основные параметры

Настройки Hwaro находятся в `config.toml` в корне репозитория:

```toml
title = "warp-wiki"
description = "Документация, руководства и полезные заметки в одном месте."
base_url = "https://eb-lan.github.io/warp-wiki.github.io"
default_language = "ru"
```

`base_url` должен совпадать с адресом публикации, без завершающего `/`. Если вы переименуете репозиторий или подключите собственный домен, обновите этот параметр.

## Светлая и тёмная темы

Палитра определена CSS-переменными в `static/css/site.css`. Основная тема использует графитовый фон и оранжевые акценты. Переключатель добавляет к элементу `html` атрибут `data-theme="light"` или `data-theme="dark"`.

| Переменная | Назначение |
| --- | --- |
| `--bg` | Фон страницы |
| `--surface` | Фон карточек и дополнительных блоков |
| `--text` | Основной текст |
| `--muted` | Второстепенный текст |
| `--accent` | Акцентный цвет и ссылки |
| `--border` | Разделители и границы |

Для светлой темы используются отдельные значения, чтобы текст оставался читаемым на белом фоне. Выбор посетителя хранится в `localStorage` под ключом `warp-theme`. При первом посещении открывается тёмная тема.

## Структура проекта

| Путь | Содержимое |
| --- | --- |
| `content/` | Статьи и описания разделов |
| `templates/` | HTML-шаблоны с синтаксисом Jinja2 |
| `static/css/site.css` | Палитра и оформление |
| `static/js/site.js` | Переключатель тем, меню и копирование кода |
| `i18n/ru.toml` | Русские подписи поиска |
| `.github/workflows/pages.yml` | Сборка и публикация |
| `scripts/check_site.py` | Проверка ссылок и собранных страниц |

## Поиск

Поиск встроен в Hwaro и не требует внешнего сервиса. Во время сборки создаётся `search.json` с заголовками, описаниями и содержимым статей. Браузер загружает индекс при первом открытии поиска.

Включён поиск по отдельным заголовкам: результат может вести сразу на нужный раздел длинной статьи. Тексты интерфейса меняются в `i18n/ru.toml`.
