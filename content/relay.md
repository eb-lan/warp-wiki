## Для чего нужны

**Relay-серверы @llimonix** — промежуточные зарубежные узлы для сервисов, ограничивающих доступ из России: ChatGPT, Claude, Netflix, Spotify. Сам WARP страну не меняет.

Для YouTube, Discord, Instagram и Telegram достаточно стандартных конечных точек без активации.

## Активация IP

Допускаются только активированные **IPv4-адреса**: белый список предотвращает злоупотребления.

1. В [@warp_generator_bot](https://t.me/warp_generator_bot) откройте **«Личный кабинет»**.
2. Откройте персональную ссылку кнопкой **«Активировать доступ»**.
3. Мини-приложение определит IP автоматически; дождитесь подтверждения.
4. Обновите статус в кабинете: проверьте IP и дату.
5. На третьем шаге генерации выберите гео-конечную точку с флагом.

## Когда повторять

**При изменении публичного IP:** другая Wi-Fi-сеть, переход на мобильный интернет, перезапуск роутера с динамическим адресом. Устройствам с общим IP достаточно одной активации, включая телефон.

## Если доступа нет

| Ситуация | Действие |
| --- | --- |
| IP отсутствует; соединение перестало работать | Активировать заново, проверить статус. |
| IPv6 не поддерживается | Отключить IPv6 в Wi-Fi либо сменить сеть/перейти на мобильные данные. |
| Доступ запрещён / IP заблокирован | Уточнить причину у администратора. |

## Ограничения

Выбирайте **«Определённые сайты»**: Relay предназначен для нужных сервисов, не всего трафика, YouTube или загрузки игр. Злоупотребление трафиком грозит блокировкой.
